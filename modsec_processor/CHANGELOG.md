# 更新日志 (Changelog) version 0.2.0

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.0] - 2026-09-02

### 新增 (Added)
- **告警聚合支持目标IP分组**：聚合查询按 `src_ip + dest_ip + attack_type + uri` 分组，使资产权重在聚合视图中生效
- **多IP日志监控**：采集引擎支持同时监控多个IP的日志文件
- **资产重要性管理**：Web 界面支持资产的增删改查及临时权重
- **操作历史模块**：统一展示沉底、规则、资产三类审计日志
- **HTTP Basic Auth 认证**：保护所有 API 接口
- **统一输入校验模块**：XSS、SQL注入防护

### 修复 (Fixed)
- 修复聚合模式下资产权重不生效的问题
- 修复规则热重载失效的问题
- 修复日志文件轮转后采集引擎无法自动切换的问题
- 修复前端模块拆分后功能失效的问题
- 修复搜索条件在页面刷新后丢失的问题

### 变更 (Changed)
- **采集引擎重构**：移除个人规则判断，改为查询层动态过滤
- **评分模型统一**：资产价值 = 基础值 × 用户配置权重，移除硬编码资产匹配
- **前端模块化**：将 500 行 `alerts.js` 拆分为 6 个独立模块
- **默认端口**：rsyslog 转发端口改为 5514（避免 root 权限要求）

### 安全 (Security)
- 敏感信息不再硬编码，默认密码改为随机生成
- 全局异常处理，防止堆栈信息泄露
- 前端数据输出自动进行 HTML 转义（XSS 防御）


## [0.1.0] - 2026-08-28

### 新增 (Added)
- **初始 MVP 版本发布**
- 告警采集引擎（ModSecurity 日志解析）
- 金钱驱动评分模型（资产价值 × 攻击危害 / 处置成本）
- 个人沉底规则（24小时过期，仅个人可见）
- 沉底操作（单条 / IP批量 / 聚合沉底）
- 规则管理（创建、删除、启用/禁用）
- 资产管理（权重配置）
- 审计日志（JSON + SQLite 双写）
- 前端界面（告警列表、规则管理、资产管理、操作历史）
